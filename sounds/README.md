# Записи двигателя

Звук собирается из коротких петель на ровных оборотах. Наборы лежат в подпапках, а переключаются в интерфейсе («Звук двигателя: Отсек / Салон / Синтез»).

| Набор | Откуда | Файлы |
| --- | --- | --- |
| `bay/` | моторный отсек, впуск с индивидуальными дросселями | `idle` (~2200), `mid` (5000), `high` (8000), `mid_off` (4500), `high_off` (8000) |
| `cabin/` | салон S2000 на месте | `idle` (900), `mid` (5000), `high` (8000) |

Как сделаны петли:

- обороты определены по частоте вспышек (4 цилиндра: частота = обороты / 30), для салона сверены с тахометром в кадре;
- участок разгона или сброса газа растянут во времени так, чтобы обороты в петле стали постоянными;
- шум между гармониками двигателя (кратными 1/4 частоты вспышек) приглушён на 10 дБ, гул ниже 25 Гц срезан;
- громкость петель выровнена.

Своя запись:

- Форматы: `.mp3`, `.wav`, `.ogg` или `.m4a`.
- Длина: 1–6 секунд, обороты внутри клипа не должны меняться.
- Слой: `load: 'on'` — под газом, `'off'` — сброс газа, `'any'` — оба. Файлы `*_off` необязательны.
- Обороты записи (`rpm`) и состав набора задаются в объекте `PACKS` в `index.html`.
- Петли склеиваются автоматически, резать их вручную не нужно.

Записи читаются через `fetch`, поэтому страницу нужно открывать через сервер (`python -m http.server`) или GitHub Pages, а не двойным кликом по файлу.
