# Записи двигателя

Положите сюда записи двигателя на ровных оборотах. Если папка пустая, страница синтезирует звук сама.

| Файл | Обороты записи |
| --- | --- |
| `idle.mp3` | ~900 (холостой ход) |
| `mid.mp3` | ~4000 |
| `high.mp3` | ~8000 (VTEC включён) |

- Форматы: `.mp3`, `.wav`, `.ogg` или `.m4a`.
- Длина: 2–6 секунд, обороты внутри клипа не должны меняться.
- Достаточно одного файла, но лучше все три: между соседними записями звук плавно смешивается, а тон подстраивается под текущие обороты.
- Петли склеиваются автоматически, резать их вручную не нужно.
- Если обороты записи другие, поправьте `rpm` в массиве `SAMPLES` в `index.html`.

Записи читаются через `fetch`, поэтому страницу нужно открывать через сервер (`python -m http.server`) или GitHub Pages, а не двойным кликом по файлу.

Кладите сюда только записи, на которые у вас есть права: свои или под свободной лицензией (CC0, CC-BY с указанием автора).
