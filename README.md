# F20C · DOHC VTEC, интерактивная 3D-модель

Рядная четвёрка F20C объёмом 2.0 л с DOHC VTEC, которую можно раскрутить до отсечки 9000 об/мин прямо в браузере. Один HTML-файл, three.js с CDN, без сборки, моделей, текстур и аудиофайлов.

**Демо:** https://hykkky.github.io/f20c-vtec/

## Запуск

Откройте `index.html` в браузере. Нужен интернет, чтобы подгрузить three.js с jsDelivr.

Если браузер не пускает модули с `file://`, запустите локальный сервер:

```powershell
python -m http.server 8000
```

и откройте http://localhost:8000.

## Что умеет

- **Газ:** ползунок, кнопка-педаль (держать), клавиша `W` / `↑` или курок R2 геймпада (Gamepad API).
- **VTEC:** выше 6000 об/мин ЭБУ подаёт масло к штифтам коромысел. Штифт каждого цилиндра сдвигается только тогда, когда его коромысла стоят на базовой окружности кулачка, поэтому в замедлении видно, как цилиндры переходят на «злой» профиль по очереди. Ниже 5800 об/мин VTEC отключается (гистерезис). Режимы: «Авто», «Выкл» и «Вкл».
- **Клапанный механизм:** на каждую пару клапанов два низких кулачка и один высокий посередине, три коромысла с роликами и выдвижные штифты. Ось коромысел подсвечивается синим, когда в канале есть давление масла.
- **Отсечка:** у 9000 об/мин топливо отключается, стрелка дрожит на ограничителе, вспышек в цилиндрах нет.
- **Виды:** сплошной (клапанная крышка снята, её можно вернуть), разрез и стекло. Камеры: общий план, ГБЦ, VTEC крупным планом, вид спереди вдоль коленвала и низ.
- **Замедление:** анимация 1×, 1/8, 1/40 или 1/200. Звук и тахометр всегда идут в реальном времени.
- **Данные:** тахометр, средняя скорость поршня (25,2 м/с на 9000), график подъёма клапанов выбранного цилиндра с перекрытием, такт, состояние штифтов во всех восьми группах.
- **Звук:** три варианта на выбор («Звук двигателя»).
  - «Отсек» — запись из моторного отсека, впуск с индивидуальными дросселями, отдельные петли для разгона и сброса газа.
  - «Салон» — запись из салона S2000, настоящий холостой 900 об/мин, звук глуше.
  - «Синтез» — Web Audio: частота вспышек, впускной шум, «выстрелы» при сбросе газа.

  Петли смешиваются по оборотам и положению газа, тон подстраивается под обороты. Как они нарезаны и почищены, описано в [sounds/README.md](sounds/README.md).

Клавиши: `W`/`↑` газ, `Пробел` пауза, `V` вид, `C` камера, `1`–`4` цилиндр, `M` звук.

## Что реально, а что упрощено

Реальные значения: диаметр цилиндра 87 мм, ход поршня 84 мм, длина шатуна 153 мм, порядок работы 1-3-4-2, плоский коленвал (шейки 1/4 и 2/3 в противофазе), распредвалы вдвое медленнее коленвала, отсечка 9000 об/мин, VTEC на впуске и выпуске.

Упрощено:

- Профили кулачков (подъём, длительность, фазы), угол наклона клапанов, передаточное число коромысел и шаг цилиндров подобраны для наглядности, а не взяты из заводских данных.
- Условие включения VTEC: только обороты. Настоящий ЭБУ смотрит ещё нагрузку, скорость и температуру.
- Нет цепи ГРМ, маслонасоса, впуска и выпуска. Пропорции деталей приблизительные.
- Динамика оборотов и звук — модель, а не измерения.

Не используйте модель как справочник для ремонта.

## Технологии

- [three.js](https://threejs.org/) 0.160 (ES-модули через import map), OrbitControls, RoomEnvironment.
- Геометрия строится кодом: кулачки — по функции подъёма, пружины — по спирали, щёки коленвала — экструзией контура.
- Web Audio API: PeriodicWave, WaveShaper, биквадратные фильтры.

Проект не связан с Honda Motor Co. Название F20C используется только как описание моделируемого двигателя.
